# misuo
📊 MISUO Sales Dashboard

Welcome to the MISUO Sales Dashboard repository! This project presents an interactive analytics dashboard designed to monitor key sales metrics, order fulfillment rates, top-performing product lines, regional distribution, and sales channel efficiency for MISUO.

📌 Executive Summary

The dashboard aggregates operational and financial metrics to provide actionable insights into sales performance, logistics, and customer demographics across different sales channels.

Key Performance Indicators (KPIs)

Total Sales Revenue (إجمالي المبيعات): EGP 1,289,724

Total Number of Orders (عدد الطلبات): 125

Average Selling Price (متوسط سعر البيع): EGP 10,437

On-Time Delivery Rate (نسبة الطلبات المسلمة في ميعادها او قبل الميعاد): 39%

Pending / Delayed Orders Rate (نسبة الطلبات التي لم تُسلّم): 83%
